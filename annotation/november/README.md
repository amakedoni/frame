# Разметка участника A к 18 ноября

Александр завершил свой проход по 60 комментариям и 60 дорожным снимкам с помощью Codex. По уточнению условий, которое передал Александр, преподаватель разрешил такой способ при наличии отдельных результатов каждого участника. Отдельный черновой проход для Владимира также выполнен с помощью ассистента.

| Набор | Всего заданий | `accept` | `discuss` | Метки |
| --- | ---: | ---: | ---: | --- |
| [Комментарии YouTube](A_text_assistant.json) | 60 | 55 | 5 | 50 `ham`, 5 `spam` |
| [Дорожные фотографии](A_road_assistant.json) | 60 | 51 | 9 | 157 рамок, включая рамки на спорных снимках |

Комментарии взяты из YT‑100K. Для фотографий использована опубликованная разметка EPDD. Рамки сверены с изображениями и исправлены по [codebook](../../docs/annotation_codebook.md), затем снимки проверены повторно. Распределение рамок по классам: D00 — 64, D10 — 27, D20 — 39, D40 — 27. Причины сомнений сохранены в соответствующих заданиях.

В опубликованных файлах есть идентификаторы, метки, координаты и контрольные суммы заданий. Исходные комментарии и фотографии передаются в отдельном архиве пилота. `predictions` — поле Label Studio для разметки, полученной с ассистентом; каждый результат помечен способом получения. Ручное время участников для этого прохода не записано.

Для сравнения двух версий используйте [скрипт сравнения](../../scripts/compare_november_exports.py) с флагом `--assistant` и исходными файлами заданий из архива. Он сопоставит результаты по ID и покажет, сколько общих объектов имеют валидную разметку.

## Черновая разметка участника B

| Набор | Файл | Заданий | `accept` | `discuss` | Предварительные метки |
| --- | --- | ---: | ---: | ---: | --- |
| Комментарии | [B_text_assistant.json](B_text_assistant.json) | 60 | 48 | 12 | 54 `ham`, 6 `spam` |
| Фотографии | [B_road_assistant.json](B_road_assistant.json) | 60 | 5 | 55 | 79 рамок: D00 — 23, D10 — 3, D20 — 31, D40 — 22 |

Проход B выполнен ассистентом независимо от результатов A и без использования исходных меток. Рамки и классы на спорных фотографиях предварительные: тонкие трещины и границы участков требуют ручной проверки. Время ручной работы не измерялось. Как и в опубликованной версии A, исходные материалы заменены на `item_id` и SHA-256 поля `data`; полные файлы для импорта Label Studio хранятся отдельно вместе с исходным архивом.
