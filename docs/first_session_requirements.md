# Первая самостоятельная работа

Дата занятия: 21 октября 2026 года. Основание — предоставленный план работы над курсовой.

1. Довыбрать датасеты: YouTube Spam Collection и RDD2022.
2. Завести журнал работы.
3. Составить предварительный список источников пополнения реальными данными.
4. Начать анализ исходных датасетов.

К сдаче нужна ссылка на журнал в общей таблице пары. В самом журнале должны быть ссылки на репозиторий и ноутбук с EDA.

Дальнейшие сроки из плана:

- 18 ноября 2026 года: ручной сбор закончен, написан codebook, размечена пилотная версия не менее 50 объектов.

Для первой самостоятельной не требуется выдавать сбор, ручную разметку, синтез или обучение за уже выполненные этапы. Анализ после обогащения появится после фактического добавления новых данных.
