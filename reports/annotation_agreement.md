# Сверка пилотной разметки к 18 ноября

Сопоставлены [результаты Александра и Владимира](../annotation/november/README.md) по общим ID. Контрольные суммы заданий совпали с архивом пилота. Записи `discuss` оставлены для разбора и исключены из расчёта пригодных пар.

| Набор | Объектов с двумя записями | Пригодные пары | Пары для разбора |
| --- | ---: | ---: | ---: |
| Комментарии | 60 | 47 | 13 |
| Фотографии | 60 | 5 | 55 |
| Всего | 120 | 52 | 68 |

На 47 пригодных парах комментариев совпали 43 метки `ham` и 4 метки `spam`. Доля совпадений и κ Коэна равны 1,00 для этой подвыборки. По пяти пригодным парам фотографий сопоставлено 5 рамок при IoU ≥ 0,5. Классы этих рамок совпали, средний IoU — 0,792. Остались 2 несопоставленные рамки A и 1 рамка B.

Пригодных пар по ID больше 50 суммарно. Для внутреннего плана с подсчётом по каждому набору ещё предстоит разобрать спорные записи. Снимки посчитаны по ID. Участки съёмки требуют уточнения для подсчёта уникальных физических дефектов.

Проверку можно повторить [скриптом](../scripts/compare_november_exports.py) с флагом `--assistant` и файлами `text_tasks.json` и `road_tasks.json` из архива пилота.
