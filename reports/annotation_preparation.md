# Подготовка ручного сбора и разметки

Дата: 22 октября 2026 года.

Подготовлен [codebook 0.1](../docs/annotation_codebook.md), отдельные конфигурации Label Studio для двух задач и [план смешанного сбора](../docs/manual_collection_plan.md). Настроены две отдельные локальные базы Label Studio 1.23.2 для участников A и B. Локальные серверы слушают только 127.0.0.1, на портах 8081 и 8082.

## Задания пилота

| Проверка | Результат |
| --- | --- |
| Уникальные комментарии на участника | 50 |
| Уникальные изображения на участника | 50 |
| Наборы и ID у A/B | Совпадают |
| Исходные метки, рамки и предсказания в импорте | Отсутствуют |
| Проекты в каждой базе | YouTube pilot и RDD pilot |
| JSON-экспорт без ответов | Проверен во всех четырёх проектах, по 50 заданий |
| Созданные ответы аннотаторов | 0 |

Пилот собран с seed 42 из исходных наборов. Для комментариев использованы 25 исходных ham и 25 spam, равномерно по пяти файлам; исходные метки скрыты. Для снимков выбраны 13 заданий с опорным классом D40, 13 с D20, 12 с D10 и 12 с D00. Изображение может содержать несколько классов: это не распределение всех рамок. Исключены известные точные повторы, точные пересечения с официальным test и участники списка кандидатов на близкие повторы.

Хеши извлечённых изображений сверены с первым EDA. Автоматические проверки покрывают воспроизводимость выбора, удаление повторов, исключение известных пересечений, отсутствие ответов в импорте, защиту существующих файлов от перезаписи и CRC при извлечении удалённого ZIP. Пять тестов проходят. В браузере проверены загрузка снимка, ID, классы, поле времени и отсутствие готовых рамок. Ни одной аннотации при проверке не отправляли.

Это пилот проверки правил на исходных данных, его объём не увеличивает ручное обогащение. После нового сбора нужно подготовить аналогичные задания на новых данных и получить ответы обоих участников.

## Внешние кандидаты и собственная съёмка

Получены 12 файлов из Figshare, DOI `10.6084/m9.figshare.21214400.v3`. В [метаданных источника](https://api.figshare.com/v2/articles/21214400) указана лицензия CC BY 4.0. Сохранены авторы, URL, дата получения, исходные архивные пути, размеры и SHA-256. Скачано 5 824 162 байта изображений через проверяемые HTTP Range; полный ZIP размером 1 031 634 487 байт не загружался.

Все 12 файлов различаются по пикселям; точных совпадений с американской частью RDD2022 нет. Минимальные расстояния dHash до неё составили 10–18. Это только автоматическая предварительная проверка. На обзорном листе повторяются виды небольшого участка дороги при разной погоде и освещении, поэтому независимость конкретных дефектов ещё не установлена. Снимки находятся в общей временной группе до ручного просмотра.

Принятых людьми новых снимков — 0. Собственные фотографии и новые комментарии пока не добавлены. Чужие готовые рамки из Figshare не получались и в задания не включались.

Следующий практический шаг: оба участника проходят пилот по одной инструкции, параллельно отбирают внешние кадры и добавляют собственные снимки и новые комментарии с метаданными. Согласованность рассчитывается после появления настоящих независимых ответов, до их обсуждения.
