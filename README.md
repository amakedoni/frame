## Что проверено

YouTube Spam: 1 956 исходных комментариев; после удаления 197 точных повторов текста остаётся 1 759 уникальных. Пропусков текста и конфликтующих меток у точных повторов не обнаружено. Сохранён предварительный манифест 1 500 текстов, по 750 на класс.

RDD2022: исследована **только американская часть train**, все 4 805 изображений и 11 014 рамок. Все файлы читаются; размеры 640 × 640 согласованы с XML, координаты рамок допустимы. Найден один повтор снимка по пикселям и одно точное совпадение train с официальным test. Для 28 пар кандидатов на близкие повторы нужна визуальная проверка. Сохранён предварительный манифест 3 000 уникальных валидных снимков.

Класс D40 редок: 135 рамок, около 1,23% всех объектов американской части. Подробные распределения приведены в ноутбуке. Эти числа не описывают весь набор RDD2022 из шести стран.

Начальный анализ выполнен **до обогащения**. Новые реальные примеры ещё не собраны, независимая ручная разметка и обучение не выполнялись. Манифесты не являются готовым train/validation/test: сначала нужно проверить близкие повторы и сформировать группы участков дороги.

## Запуск

Нужен Python 3.12. Зависимости зафиксированы в `requirements.txt` по фактически использованному окружению.

Команды для Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe scripts/download_data.py
.venv\Scripts\python.exe scripts/eda.py
```

В Linux/macOS аналогично используется `.venv/bin/python`. Откройте `notebooks/01_initial_eda.ipynb` в Jupyter или VS Code, выберите Python из созданного окружения и выполните все ячейки. Код ищет корень репозитория автоматически; запускать можно из корня или папки `notebooks`.

Загрузчик использует официальные источники. Старый отдельный S3-адрес американского ZIP на дату проверки возвращал 403. Поэтому предусмотрено извлечение только вложенного файла `RDD2022/United_States.zip` из официального Figshare посредством ограниченного HTTP Range, с проверкой размеров и CRC. Полный архив RDD2022 на 12 GiB не скачивается. Локально требуется около 0,5 GiB для архивов плюс место для окружения и результатов.

## Данные и лицензии

- [YouTube Spam Collection, UCI](https://archive.ics.uci.edu/dataset/380/youtube+spam+collection), Alberto T., Lochter J., DOI 10.24432/C58885 — CC BY 4.0.
- [RDD2022, Figshare](https://figshare.com/articles/dataset/RDD2022_-_The_multi-national_Road_Damage_Dataset_released_through_CRDDC_2022/21431547), Arya D. и соавторы — CC BY 4.0.
- [Статья авторов RDD2022](https://arxiv.org/pdf/2209.08538) и [репозиторий авторов](https://github.com/sekilab/RoadDamageDetector).

В этом репозитории опубликованы профили и манифесты, а не полные исходные архивы. В текстовых профилях нет имён авторов и самих комментариев. Изменения относительно источника: нормализация крайних пробелов, удаление точных повторов для рабочих манифестов, вычисление признаков и иллюстрации исходных рамок. Иллюстрации RDD2022 в отчёте — производные материалы под CC BY 4.0 с указанием источника.

Для новых реальных данных условия проверяются отдельно: лицензии исходных наборов не распространяются автоматически на новые комментарии или сторонние снимки. SMS Spam Collection отмечен только как резерв с другим контекстом, а не как согласованный источник для смешивания с YouTube.
